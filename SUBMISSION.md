# Submission checklist

Push all of this to `main` before the deadline announced by the organisers.

- [ ] Source code / build files
- [ ] `README` updated: what it does, how to run it
- [ ] `DEMO.md` - link to a 2-3 min video or live demo, plus screenshots
- [ ] Team + tower confirmed at the top of the README
- [ ] Anything judges need to test it (sample data, credentials, hardware list)

Judging uses whatever is on `main` at the deadline.
